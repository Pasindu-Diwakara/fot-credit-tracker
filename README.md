# 🎓 FOT Academic & Career Dashboard (RUSL)

An all-in-one web application built specifically for students at the Faculty of Technology, Rajarata University of Sri Lanka (RUSL). This platform bridges the gap between academic progress tracking and professional career planning.

---

## ✨ Key Features

* 📊 **Detailed Credit Breakdown:** Easily monitor your graduation requirements with Compulsory vs. Optional credit tracking.
* 📈 **Academic Tracking:** Real-time GPA calculation and progression monitoring.
* 📄 **Transcript Generator:** Instantly create and preview an unofficial academic transcript.
* 💼 **Career Hub:** Map out industry pathways and browse live job opportunities.

---

## 🛠️ Tech Stack

* **Frontend & Architecture:** HTML5, CSS3, JavaScript (Vanilla / Custom Modularity)
* **Styling / UI:** Custom Glassmorphism & Modern Dark-Mode Layouts
* **Deployment:** Hosted live on Vercel
